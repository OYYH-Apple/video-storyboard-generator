### 3. 15秒镜头规则与逻辑检查

**核心规则：单个镜头时长不超过设定上限（默认15秒，可自定义）**

| 时长范围 | 适用场景 | 节奏 |
|---------|---------|------|
| <10秒 | 快节奏、开场、强调 | 紧凑 |
| 10-15秒 | 标准镜头（默认上限） | 适中 |
| 15-20秒 | 信息密集型 | 较慢 |
| >20秒 | 特殊叙事需求 | 很慢 |

**智能逻辑检查**（生成分镜前自动执行）：
- ✅ 分镜内部逻辑（内容完整性、时长合理性、动作可行性）
- ✅ 分镜间逻辑（叙事连贯性、空间逻辑、情绪连贯性）
- ✅ 流畅度评估（节奏检查、视觉多样性、音画同步）

超过上限的镜头自动拆分，确保视觉节奏紧凑。

### 6. 角色提示词生成（故事/剧情类）

**包含内容：**

## 🚀 如何使用

### 快速开始

**推荐新手先查阅**：[一页纸速查表](references/quick-reference.md) 📋

**在 Claude 对话中使用：**

```
我想做一个[你的视频主题]的分镜脚本
```

**Claude 会执行 7 阶段工作流程：**

```
阶段0: 用户画像（可选）
   ↓ 检测到画像 → 询问"是否使用之前的偏好设置？"
阶段1: 视频类型识别 + 头脑风暴（10+问题）
   ↓ 确定主题、时长、风格、版式
阶段2: 段落结构设计
   ↓ 根据类型定制段落结构
阶段3: 镜头拆分（15秒规则）
   ↓ 超过上限自动拆分
阶段4: 逻辑检查
   ↓ 5项内部检查 + 4维度连贯性检查
阶段5: 生成分镜脚本（极简/专业版）
   ↓ 包含Seedance提示词（如选择）
阶段6: 文件保存
   ↓ 默认保存到 ./docs/
阶段7: 更新用户画像
   ↓ 记录本次偏好选择
```

---

```
用户：我想做一个《人类简史》的书籍介绍视频

Claude：我检测到您之前的使用偏好记录。是否使用之前的偏好设置？

- 视频时长预期多久？
- 需要生成Seedance 2.0提示词吗？
- 需要音效/BGM建议吗？
...
```

## 🎬 15秒拆分规则

### 拆分策略

| 原镜头时长 | 拆分建议 |
|-----------|---------|
| 15秒以内 | 保持单个镜头 |
| 16-30秒 | 拆分为2个镜头 |
| 31-45秒 | 拆分为3个镜头 |
| 45秒以上 | 拆分为N个镜头 |

### 运镜变化规则

拆分后的相邻镜头**必须**有运镜变化：

| 前一个镜头 | 推荐后一个镜头 |
|-----------|---------------|
| 推近 | 环绕/特写/拉远 |
| 环绕 | 推近/跟拍/摇移 |
| 跟拍 | 推近/特写/定格 |
| 拉远 | 推近/汇聚 |
| 特写 | 拉远/环绕/摇移 |
