# 微表情精准控制指南

## 概述

微表情是视频中传递情感和塑造角色的重要元素。本指南提供**三步法微表情控制**，帮助精准控制视频中人物的微表情：

1. **控制情绪强度** - 设定情绪的强弱程度
2. **给微表情一个发生原因** - 解释为什么会出现这个表情
3. **给情绪加时间顺序** - 描述情绪的演变过程

---

## 三步法详解

### 第一步：控制情绪强度

情绪强度决定了微表情的明显程度，分为五个等级：

| 强度等级 | 程度 | 外观特征 | 适用场景 |
|---------|------|---------|---------|
| **1级** | 微弱 | 仅眼神变化，面部肌肉几乎不动 | 内心活动、隐藏情感 |
| **2级** | 轻微 | 嘴角或眉毛轻微变化 | 日常对话、轻微反应 |
| **3级** | 中等 | 明显但克制的面部变化 | 正常情感表达 |
| **4级** | 较强 | 明显面部变化，肌肉紧绷 | 情感高潮前奏 |
| **5级** | 强烈 | 完整的表情呈现 | 情感爆发、重要时刻 |

**情绪强度描述格式：**
```text
[情绪类型]（强度X级）：[外观特征描述]
```

**示例：**
```text
紧张（强度2级）：眉头轻微皱起，眼神略显不安
开心（强度3级）：嘴角上扬，眼角有笑意
愤怒（强度4级）：眉毛紧锁，下巴肌肉紧绷，眼神锐利
悲伤（强度5级）：眼泪涌出，嘴角颤抖，面部肌肉松弛
```

---

### 第二步：给微表情一个发生原因

每个微表情都应该有明确的触发原因，使表情更有说服力。

#### 常见微表情触发原因

| 情绪类型 | 常见触发原因 |
|---------|-------------|
| **紧张** | 面对压力、即将发生重要事件、担心结果 |
| **开心** | 收到好消息、见到喜欢的人、完成目标 |
| **愤怒** | 遭遇不公、被误解、看到不当行为 |
| **悲伤** | 失去重要事物、回忆往事、分离 |
| **惊讶** | 意外发现、突然的消息、出乎意料的结果 |
| **困惑** | 信息不足、矛盾情境、难以理解的事物 |
| **恐惧** | 威胁、危险、未知事物 |
| **期待** | 等待重要结果、盼望某事发生 |

**原因描述格式：**
```text
原因：[触发原因描述]
```

**示例：**
```text
原因：收到面试通过的通知
原因：发现朋友背叛了自己
原因：回忆起童年的美好时光
原因：面对即将到来的重要演讲
```

---

### 第三步：给情绪加时间顺序

情绪是动态的，描述情绪的演变过程使微表情更加真实。

#### 时间顺序描述模式

**基本模式：**
```text
[起始状态] → [变化过程] → [结束状态]
```

**时间节点：**
- **0-30%**：情绪萌芽阶段
- **30-70%**：情绪发展阶段
- **70-100%**：情绪稳定或消退阶段

**时间顺序描述格式：**
```text
情绪演变：[起始状态]（0-X秒）→ [变化过程]（X-Y秒）→ [结束状态]（Y秒-结束）
```

**示例：**
```text
情绪演变：平静（0-2秒）→ 眉头开始皱起（2-4秒）→ 紧张定格（4-6秒）

情绪演变：嘴角微动（0-1秒）→ 笑意逐渐扩大（1-3秒）→ 完整笑容（3-5秒）

情绪演变：眼神迷茫（0-3秒）→ 逐渐聚焦（3-5秒）→ 恍然大悟（5-6秒）
```

## 完整微表情提示词格式

将三步法组合，形成完整的微表情提示词：

```text
[角色名-分镜X] 微表情：
- 情绪：[情绪类型]（强度X级）
- 原因：[触发原因]
- 演变：[起始状态]（0-X秒）→ [变化过程]（X-Y秒）→ [结束状态]（Y秒-结束）
- 外观：[具体面部特征描述]
```

## 完整示例

### 示例1：职场故事

```text
林晓明-分镜3 微表情：
- 情绪：紧张（强度3级）
- 原因：即将向老板汇报项目进度，担心数据不够理想
- 演变：平静（0-1秒）→ 眉头逐渐皱起（1-3秒）→ 紧张定格（3-5秒）
- 外观：眉头紧锁，眼神略带不安，嘴角紧抿，喉结轻微滚动

林晓明-分镜7 微表情：
- 情绪：如释重负（强度4级）
- 原因：老板认可了项目进度，紧张情绪得以释放
- 演变：紧张（0-1秒）→ 眉头舒展（1-2秒）→ 嘴角上扬（2-4秒）→ 完整笑容（4-5秒）
- 外观：眉头完全舒展，眼角出现笑意，嘴角自然上扬，肩膀下沉放松
```

### 示例2：情感故事

```text
苏小雨-分镜2 微表情：
- 情绪：思念（强度2级）
- 原因：看到桌上前任留下的照片，回忆涌上心头
- 演变：无意识（0-2秒）→ 目光停驻（2-4秒）→ 眼神温柔（4-6秒）
- 外观：目光柔和，嘴角轻微上扬后下撇，眼神略带湿润

苏小雨-分镜5 微表情：
- 情绪：悲伤（强度5级）
- 原因：意识到再也回不到从前，悲伤情绪决堤
- 演变：眼眶湿润（0-2秒）→ 眼泪涌出（2-4秒）→ 掩面哭泣（4-7秒）
- 外观：眼泪沿脸颊滑落，嘴角颤抖，面部肌肉松弛，呼吸急促
```

### 示例3：悬疑故事

```text
侦探-分镜4 微表情：
- 情绪：怀疑（强度2级）
- 原因：发现嫌疑人的证词与现场证据存在细微矛盾
- 演变：平静（0-2秒）→ 眯眼聚焦（2-3秒）→ 眉头微皱（3-5秒）
- 外观：眼神锐利，下巴略微抬起，嘴角轻微下撇

侦探-分镜8 微表情：
- 情绪：恍然大悟（强度4级）
- 原因：突然意识到关键线索被忽略了，真相即将浮出水面
- 演变：思索（0-2秒）→ 眼睛睁大（2-3秒）→ 嘴角微微张开（3-4秒）→ 目光坚定（4-5秒）
- 外观：眼睛睁大，眉毛上扬，嘴唇微张，随即恢复坚定表情
```

## 微表情强度等级详解

### 1级（微弱）- 内心活动

**特征：** 仅眼神变化，面部肌肉几乎不动

**适用场景：**
- 隐藏真实情感
- 内心独白时刻
- 社交场合的克制反应

**示例：**
```text
情绪：不悦（强度1级）
外观：眼神短暂变冷，面部肌肉不动，随后恢复正常
```

### 2级（轻微）- 轻微反应

**特征：** 嘴角或眉毛轻微变化，可被观察者捕捉

**适用场景：**
- 日常对话中的反应
- 轻微的情感波动
- 礼貌性表情

**示例：**
```text
情绪：开心（强度2级）
外观：嘴角轻微上扬，眼角有淡淡笑意
```

### 3级（中等）- 正常表达

**特征：** 明显但克制的面部变化，清晰可读

**适用场景：**
- 正常的情感表达
- 非正式社交场合
- 角色性格展示

**示例：**
```text
情绪：惊讶（强度3级）
外观：眉毛上扬，眼睛睁大，嘴唇微张
```

### 4级（较强）- 情感高潮前奏

**特征：** 明显面部变化，肌肉紧绷，情感呼之欲出

**适用场景：**
- 重要时刻前的酝酿
- 克制的强烈情感
- 冲突升级阶段

**示例：**
```text
情绪：愤怒（强度4级）
外观：眉毛紧锁，下巴肌肉紧绷，眼神锐利，鼻翼扩张
```

### 5级（强烈）- 情感爆发

**特征：** 完整的表情呈现，无法掩饰

**适用场景：**
- 情感爆发时刻
- 高潮场景
- 失控状态

**示例：**
```text
情绪：崩溃（强度5级）
外观：眼泪涌出，面部肌肉颤抖，嘴角无法控制地颤抖，呼吸急促
```

## 常见情绪的微表情特征

### 正面情绪

| 情绪 | 1级特征 | 3级特征 | 5级特征 |
|------|---------|---------|---------|
| **开心** | 眼角微弯 | 嘴角上扬，眼睛微眯 | 完整笑容，眼睛弯成月牙 |
| **期待** | 目光聚焦 | 嘴角微扬，身体前倾 | 眼睛发亮，嘴角持续上扬 |
| **满足** | 眼神柔和 | 嘴角放松上扬 | 整个面部舒展放松 |
| **自信** | 目光坚定 | 下巴微扬，嘴角平直 | 完整的自信表情 |

### 负面情绪

| 情绪 | 1级特征 | 3级特征 | 5级特征 |
|------|---------|---------|---------|
| **紧张** | 眼神略飘忽 | 眉头微皱，喉结滚动 | 眉头紧锁，嘴角紧抿，呼吸急促 |
| **悲伤** | 眼眶微红 | 眼眶湿润，嘴角下撇 | 眼泪滑落，面部肌肉松弛 |
| **愤怒** | 眼神变冷 | 眉毛下压，嘴唇紧闭 | 青筋暴起，眼睛瞪大 |
| **恐惧** | 瞳孔放大 | 眉毛上扬，嘴唇微张 | 面色苍白，身体僵硬 |

### 复杂情绪

| 情绪 | 微表情特征 |
|------|-----------|
| **矛盾** | 嘴角上扬但眉头紧锁 |
| **苦笑** | 嘴角上扬但眼角下垂 |

| **惊讶转喜悦** | 眉毛从上扬到恢复，嘴角从张到笑 |

## 微表情控制工作流程

### 步骤1：确定情绪类型

根据分镜剧情确定角色的主要情绪：
- 分析该分镜的情感基调
- 确定角色的心理状态
- 选择最匹配的情绪类型

### 步骤2：设定情绪强度

根据剧情重要性选择强度等级：
- 日常场景：1-2级
- 重要互动：3级
- 关键转折：4级
- 高潮时刻：5级

### 步骤3：设计触发原因

为微表情设计合理的触发原因：
- 原因要具体、可信
- 与剧情逻辑一致
- 原因可以是内在（想法）或外在（事件）

### 步骤4：规划时间顺序

描述情绪的演变过程：
- 设定起始状态
- 描述变化过程
- 确定结束状态
- 时间节点与分镜时长匹配

### 步骤5：撰写外观描述

将以上要素转化为具体的面部特征描述：
- 描述眉毛、眼睛、嘴巴的变化
- 注意面部肌肉的状态
- 可以加入呼吸、喉结等细节

## 注意事项

### 1. 一致性

- 微表情要与前后的情绪状态连贯
- 情绪演变要符合逻辑
- 强度变化要合理（不能突然跳级）

### 2. 精准性

- 选择最匹配的情绪类型
- 强度等级要准确反映剧情需要
- 外观描述要具体可执行

### 3. 服务叙事

- 微表情要服务于剧情需要
- 不要为表情而表情
- 每个微表情都应该有意义

### 4. 可执行性

- 外观描述要具体可想象
- 时间节点要与分镜时长匹配
- 确保AI视频工具能够理解和执行
