# 微表情精准控制指南

## 概述

微表情控制是让AI生成视频更加逼真、去除AI味的关键。本指南采用**自然语言流畅描述**的方式，将三个控制要素融入一体：

1. **情绪强度** - 通过词汇选择体现强弱（微弱/轻微/中等/明显/强烈）
2. **发生原因** - 将原因自然融入情境描述
3. **时间演变** - 用"逐渐""缓缓""突然"等词描述变化过程

**核心原则**：不拆分、不罗列，用**一段流畅的自然语言**完整描述微表情。

---

## 微表情描述三要素

### 第一要素：情绪强度（通过词汇选择）

不使用"强度1-5级"的机械标注，而是通过**词汇选择**自然体现：

| 强度 | 推荐词汇 | 效果 |
|------|---------|------|
| 微弱 | "眼神微微""嘴角几乎不""几乎看不出" | 克制、隐藏 |
| 轻微 | "眉头略动""嘴角轻扬""眼角微弯" | 自然、日常 |
| 中等 | "明显""清晰可辨""眉头紧锁" | 正常表达 |
| 较强 | "紧绷""肌肉微微颤抖""难以抑制" | 情感积蓄 |
| 强烈 | "完全""彻底""爆发""无法控制" | 情感爆发 |

### 第二要素：发生原因（融入情境）

不单独写"原因：xxx"，而是**自然融入**描述：

❌ **机械写法**：
```
原因：因为刚收到面试通过的通知，所以很开心
表情：嘴角上扬，眼睛发亮
```

✅ **自然语言写法**：
```
收到面试通过通知的瞬间，她紧绷的面容逐渐舒展，嘴角不自觉地上扬，眼中闪烁着难以抑制的喜悦光芒，整个人仿佛卸下了千斤重担。
```

### 第三要素：时间演变（用动态词汇）

不拆分"0-2秒→2-4秒"，而是用**动态词汇**描述变化：

| 变化类型 | 推荐词汇 |
|---------|---------|
| 缓慢变化 | "逐渐""缓缓""慢慢""一点一点" |
| 快速变化 | "突然""猛然""瞬间""一下子" |
| 阶段变化 | "先是...然后...""开始...接着...最终..." |
| 循环变化 | "时而...时而...""忽而...忽而..." |

## 微表情描述公式

将三要素融合为**一段自然语言**：

```
[情境/原因]，角色[情绪类型]，[时间变化词][具体面部特征]，[整体状态补充]
```

## 完整示例对比

### 示例1：紧张情绪

❌ **机械拆分写法（不推荐）**：
```
情绪：紧张（强度3级）
原因：即将向老板汇报项目
演变：平静（0-1秒）→ 眉头皱起（1-3秒）→ 定格（3-5秒）
外观：眉头紧锁，眼神不安
```

✅ **自然语言写法（推荐）**：
```
站在会议室门口等待汇报时，他的眉头逐渐紧锁，眼神中透着掩饰不住的不安，嘴角紧抿成一条线，喉结微微滚动，整个人绷得像一张拉满的弓。
```

### 示例2：开心情绪

❌ **机械拆分写法（不推荐）**：
```
情绪：开心（强度4级）
原因：收到好消息
演变：惊讶（0-1秒）→ 笑意扩散（1-3秒）→ 完整笑容（3-5秒）
外观：嘴角上扬，眼睛弯成月牙
```

✅ **自然语言写法（推荐）**：
```
看到那条好消息的瞬间，她先是愣了一秒，随即笑意从眼角开始蔓延，嘴角不自觉地上扬，整个人都被喜悦点亮，眼睛弯成两道温柔的月牙。
```

### 示例3：悲伤情绪

❌ **机械拆分写法（不推荐）**：
```
情绪：悲伤（强度5级）
原因：意识到失去
演变：眼眶湿润（0-2秒）→ 泪水流下（2-4秒）→ 掩面（4-7秒）
外观：眼泪滑落，嘴角颤抖
```

✅ **自然语言写法（推荐）**：
```
当那个事实终于被确认时，她的眼眶先是微微泛红，继而泪水不受控制地涌出，顺着脸颊缓缓滑落，嘴角颤抖着想要说什么却发不出声音，最终只能无力地低下头，肩膀微微耸动。
```

### 示例4：复杂情绪转换

❌ **机械拆分写法（不推荐）**：
```
情绪：惊讶转喜悦（强度3级→4级）
原因：意外发现
演变：惊讶（0-1秒）→ 疑惑（1-2秒）→ 喜悦（2-4秒）
外观：眼睛睁大→眉头皱起→嘴角上扬
```

✅ **自然语言写法（推荐）**：
```
看到桌上那封信的瞬间，她瞪大了眼睛，眉头微微皱起似乎在确认这是否真实，随即那双眼睛里涌动着光芒，紧绷的面容一点点舒展开来，最后整个人都沐浴在久违的笑容里。
```

## 微表情与分镜角色提示词的融合

微表情控制应**直接融入**分镜角色提示词，不需要单独列出。

### 融合格式

```text
[角色名-分镜X]: [整体状态]，[微表情描述]，[动作姿势]，[场景位置]
```

### 融合示例

#### 示例1：职场场景

```text
林晓明-分镜3: 站在会议室前方准备汇报PPT，由于担心数据不够理想，他的眉头逐渐紧锁，眼神中透着掩饰不住的不安，嘴角紧抿成一条线，整个人绷得像一张拉满的弓，手持翻页笔站在投影屏幕旁，场景2
```

#### 示例2：情感场景

```text
苏小雨-分镜5: 看到那条好消息的瞬间，她先是愣了一秒，随即笑意从眼角开始蔓延，嘴角不自觉地上扬，整个人都被喜悦点亮，眼睛弯成两道温柔的月牙，坐在办公桌前，场景1
```

#### 示例3：冲突场景

```text
王总-分镜4: 听完汇报后脸色沉下来，眉头深锁，眼神变得锐利，下巴肌肉微微紧绷，嘴唇抿成一条直线，整个人散发出压迫感，靠在椅背上盯着投影屏幕，场景2
```

## 常见情绪的微表情描述

### 正面情绪

#### 开心/喜悦

**微弱（克制）**：
```
嘴角微微上扬，眼中闪烁着淡淡的光芒，但很快又恢复平静
```

**中等（自然）**：
```
脸上绽放出明朗的笑容，眼角微微弯起，整个人看起来轻快了许多
```

**强烈（爆发）**：
```
笑意完全占据了面容，眼睛弯成月牙，整个人都在发光，忍不住轻轻跳了一下
```

#### 满足/安心

**微弱**：
```
眉头舒展开来，嘴角带着若有若无的放松
```

**中等**：
```
整个人仿佛卸下了重担，面部肌肉松弛下来，嘴角挂着满足的微笑
```

**强烈**：
```
长舒一口气，脸上是彻底放松后的平和，眼角眉梢都透着满足
```

#### 期待/兴奋

**微弱**：
```
眼神微微发亮，身体不自觉前倾
```

**中等**：
```
眼睛里闪烁着期待的光芒，嘴角挂着难以抑制的笑意
```

**强烈**：
```
整个人都兴奋起来，眼睛闪闪发亮，脸颊微微泛红，坐都坐不住
```

### 负面情绪

#### 紧张/焦虑

**微弱**：
```
眼神偶尔飘忽一下，手指不自觉地摩挲
```

**中等**：
```
眉头微微皱起，眼神中透着不安，喉结轻微滚动
```

**强烈**：
```
整个人绷得紧紧的，眉头紧锁，眼神惊惶，嘴唇微微发白
```

#### 悲伤/失落

**微弱**：
```
眼眶微微泛红，嘴角略略下撇
```

**中等**：
```
眼眶湿润，嘴唇微微颤抖，整个人都笼罩着一层淡淡的忧伤
```

**强烈**：
```
泪水不受控制地涌出，顺着脸颊滑落，肩膀微微颤抖，整个人都在抽泣
```

#### 愤怒/不满

**微弱**：
```
眼神微微变冷，嘴角略略紧绷
```

**中等**：
```
眉头紧锁，眼睛瞪大，下巴肌肉紧绷，整个人都散发着怒气
```

**强烈**：
```
脸色涨红，青筋隐约可见，眼神锐利如刀，整个人都在颤抖
```

### 复杂情绪

#### 矛盾/纠结

```
眉头时而紧锁时而舒展，嘴角微微抿起又松开，眼神在坚定和迷茫之间来回切换
```

#### 无奈/苦笑

```
嘴角勉强上扬，但眼神却是黯淡的，整个笑容都透着疲惫
```

#### 惊讶转喜悦

```
先是瞪大眼睛，继而眉头舒展，笑意从眼角开始蔓延，整个人都被惊喜点亮
```

#### 紧张转释然

```
紧绷的面容一点点舒展开来，眉头从紧锁到放松，整个人仿佛卸下了千斤重担
```

## 微表情描述要点

### 1. 用词精准

- **避免笼统**：不用"看起来很开心"，改用"嘴角上扬，眼角弯起"
- **避免过度**：不用"笑容灿烂如花"，改用"脸上绽放出明朗的笑容"
- **用动态词**：多用"逐渐""缓缓""蔓延""舒展"等动态词汇

### 2. 整体协调

- 微表情要与整体情绪一致
- 微表情要与场景氛围协调
- 微表情要与角色性格匹配

### 3. 自然而然

- 不刻意堆砌形容词
- 用生活化的语言描述
- 让读者能"看见"画面

### 4. 服务叙事

- 微表情要推动剧情
- 重要的情绪要详细描述
- 过渡情绪可以简略

## 常见错误与修正

### 错误1：机械拆分

❌ **错误**：
```
微表情：紧张（强度3级），因为汇报工作，从平静到紧张用了2秒
```

✅ **修正**：
```
站在会议室门口，他的眉头逐渐紧锁，眼神中透着掩饰不住的不安
```

### 错误2：过度描述

❌ **错误**：
```
她的眼睑微微颤动，眼轮匝肌收缩，嘴角提肌轻微上拉，颧大肌收缩形成笑意...
```

✅ **修正**：
```
她的眼角微微弯起，嘴角挂着淡淡的笑意
```

### 错误3：脱离情境

❌ **错误**：
```
他很开心，嘴角上扬，眼睛发亮（没有说明为什么开心）
```

✅ **修正**：
```
看到那封期待已久的录取通知书，他紧绷的面容瞬间舒展，嘴角不自觉地上扬
```

### 错误4：情绪跳跃

❌ **错误**：
```
上一秒还在痛哭，下一秒就开怀大笑（没有过渡）
```

✅ **修正**：
```
泪水还挂在脸上，但看到他的那一刻，嘴角开始颤抖着上扬，终于忍不住破涕为笑
```

## 微表情描述词库

### 眉毛相关

| 情绪 | 描述词汇 |
|------|---------|
| 困惑 | 眉头紧锁、眉毛微皱、眉心打结 |
| 惊讶 | 眉毛上扬、眉毛挑起 |
| 思考 | 眉头微蹙、眉毛聚拢 |
| 愤怒 | 眉毛倒竖、眉头深锁 |
| 放松 | 眉头舒展、眉毛平顺 |

### 眼睛相关

| 情绪 | 描述词汇 |
|------|---------|
| 开心 | 眼睛发亮、眼角弯起、眼中闪烁光芒 |
| 悲伤 | 眼眶泛红、眼眶湿润、眼中含泪 |
| 恐惧 | 瞳孔放大、眼睛瞪大、眼神惊惶 |
| 坚定 | 眼神坚定、目光如炬、眼里透着决意 |
| 温柔 | 眼神柔和、目光温柔、眼里满是柔情 |

### 嘴巴相关

| 情绪 | 描述词汇 |
|------|---------|
| 开心 | 嘴角上扬、嘴角弯起、笑容绽放 |
| 悲伤 | 嘴角下撇、嘴角颤抖、嘴唇发白 |
| 紧张 | 嘴唇紧抿、嘴角绷紧、嘴唇微微发抖 |
| 思考 | 嘴角微动、嘴唇轻启 |
| 放松 | 嘴角放松、嘴唇微张 |

### 整体面部

| 情绪 | 描述词汇 |
|------|---------|
| 紧张 | 面部紧绷、肌肉紧绷、整个人绷着 |
| 放松 | 面容舒展、面部肌肉松弛、整个人放松下来 |
| 情绪变化 | 表情凝固、面容变化、五官逐渐舒展 |

### 动态词汇

| 类型 | 词汇 |
|------|------|
| 缓慢 | 逐渐、缓缓、慢慢、一点一点、渐渐 |
| 快速 | 突然、猛然、瞬间、一下子、立刻 |
| 过程 | 先是...继而...、开始...接着...、从...到... |
| 转折 | 然而、但、随即、突然 |
